# CCTV Shift Log | سجل تسليم الوردية
الحسين علي أبو طالب — Alhussin Ali Abutalib

مشروع تدريبي أُعد بمساعدة الذكاء الاصطناعي لدعم مهارات CCTV Operations وTroubleshooting وتوثيق الأعطال. يحول نتائج فحص يدوي من CSV إلى تقرير HTML عربي قابل للطباعة وملخص JSON، دون اتصال بالكاميرات أو أي خدمات خارجية.

## التشغيل
Python 3.10+، دون مكتبات إضافية:
```sh
python shift_log.py examples/checks.csv --out reports
python -m unittest discover -s tests -v
```
افتح reports/handover.html. على Windows يمكن استخدام py بدل python. على الجوال يمكن تشغيله في Codespaces وتنزيل التقرير. توجد نسخة نموذجية في demo.

## ماذا يعرض؟
- فحص العرض المباشر، واسترجاع التسجيلات، وجودة الصورة: pass / fail / unchecked.
- وجود أي fail يصنف الكاميرا «يتطلب متابعة»، حتى مع فحوص غير مكتملة.
- دون fail ومع unchecked تصنف «الفحص غير مكتمل»؛ جميعها pass تصنف «اكتمل الفحص».
- يعدد حالات الفشل التي لم يسجل لها رقم بلاغ. لا ينشئ بلاغات آليًا.
- المثال: 4 كاميرات افتراضية، 1 اكتمل فحصها، 2 تتطلبان متابعة، 1 غير مكتملة، وحالة فشل واحدة بلا بلاغ.

## خطوات العرض في مقابلة
1. شغّل المثال واشرح الفرق بين ظهور الصورة ونجاح استرجاع التسجيلات.
2. أشر إلى CAM-002: العرض ناجح والاسترجاع فاشل؛ يجب متابعة البلاغ LAB-001.
3. أشر إلى CAM-004: فشل العرض مع فحوص لم تنفذ ورقم بلاغ مفقود.
4. استكمل الفحوص وسجل الإجراء التالي ثم أعد توليد التقرير.

## الحدود وحماية المعلومات
هذه أداة تعليمية للفحص اليدوي وليست VMS أو نظام مراقبة لحظي أو سجل تدقيق موثوقًا. لا تحفظ تاريخ تغييرات أو هوية فاحص أو توقيتًا؛ الملف يمثل لقطة يدوية واحدة. لا تنفذ تحليل فيديو أو تعرّف وجوه أو تسجيلًا أو تشخيصًا آليًا. جميع البيانات في المستودع افتراضية، ولا تمثل جهة عمل أو تركيبًا فعليًا.

استخدم CAM-001 وLAB-001 وأرقامًا افتراضية فقط في العرض العام. لا ترفع خرائط أو مواقع أو عناوين IP أو أسماء أشخاص أو صورًا أو تسجيلات أو بيانات عمل حقيقية. التحقق من شكل المعرفات لا يزيل المعلومات الحساسة من النص الحر؛ راجعه قبل أي مشاركة. اكتمال الفحوص المدخلة لا يضمن التغطية أو الامتثال أو مدة التسجيل. إجراءات الصيانة تتم عبر المختص المخول وإجراءات الموقع.

CSV: الأعمدة بالترتيب الموجود في المثال، 1–1000 سجل، 1MB حد إدخال، لا تكرار للمعرفات، الإجراء سطر واحد حتى 300 حرف. المخرجات بالأسماء نفسها تستبدل؛ عند خطأ الإدخال لا تعتمد على تقارير قديمة. exit 0 نجاح توليد التقرير وليس نجاح جميع الفحوص؛ exit 2 خطأ.
